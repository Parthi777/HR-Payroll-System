Usage rules

Keep the artwork proportions. Leave clear space equal to at least one quarter of the symbol height around the visible artwork. Use the symbol alone when a product lockup would be narrower than 240 CSS pixels or the parent lockup narrower than 140 CSS pixels. Product symbols are best at 24px or larger; the 16px favicon is a size-constrained fallback.

Use white or very pale backgrounds for the coloured light version. Use the reversed version on charcoal. Use all-black or all-white variants on busy or strongly coloured surfaces. Never add shadows, gradients, outlines, stretch, rotate, or recolour individual letters.

Mobile icons intentionally have square, opaque backgrounds. The operating system applies its own corner mask. Adaptive Android foregrounds and PWA maskable icons include extra safe padding.

SVG lettering is outlined, so no font installation is required. The original AI-generated lettering is not an identified font; these files are cleaned vector reconstructions, not original typeface source files.

Developer handoff

Read README.md and INTEGRATION.md in the ZIP. The package contains logo masters, pre-rendered PNGs, web manifests, platform icon resources and colour tokens. App icons are static assets; build-time integration and device previews remain the app developer’s responsibility.
